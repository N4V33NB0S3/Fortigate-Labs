# Fortigate-Labs

Hands-on FortiGate labs, notes, and screenshots. Each lab lives in its own folder so new topics can be added without losing the steps and troubleshooting behind earlier work.

## Lab index

| Lab | Topic | Status |
| --- | --- | --- |
| [VIP-Lab](VIP-Lab/README.md) | Day 2 — Virtual IP (VIP) and destination NAT (DNAT): publish an internal HTTP server on external TCP/8080 | Completed |

## Adding a lab

Create a folder for the lab, keep its screenshots in that folder, and add a `README.md` with the topology, configuration, test steps, troubleshooting, and lessons learned. Then add a row for it to this index.
